Privacy Policy — GTA CLIPS uploader

Last updated: 21 November 2026

Who this applies to

GTA CLIPS uploader is a private tool used by a single person, the operator of the YouTube channel Leonida Clips. It has no other users. This policy describes what the tool does with data, including data obtained through YouTube API Services.

Data accessed through YouTube API Services

The tool uses the YouTube Data API with one OAuth scope, youtube.upload, granted by the channel operator. It uses this access only to upload videos to the operator's own channel, as private. It does not request, read, collect, store or share any other YouTube data, and it does not access any other user's account.

Data stored

  • The OAuth token for the operator's channel, stored locally on the operator's computer with access restricted to the operator's user account. It is never sent anywhere except to Google.
  • Video files produced by the tool and their titles and descriptions, stored locally until they are uploaded and then deleted after 7 days.

The tool does not use cookies, analytics, advertising or tracking, and it does not collect personal information from anyone.

Sharing

No data is sold, shared with or disclosed to third parties. Videos are sent only to YouTube.

Google policies

By using YouTube features through this tool, the operator is bound by the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time from the Google security settings page: https://myaccount.google.com/permissions. When access is revoked, the stored token is deleted.
